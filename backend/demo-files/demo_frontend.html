3. 后端代理实现

@app.get("/api/proxy/image") async def proxy_image(url: str): """全局图片代理端点 - 解决前端跨域获取图片的问题""" import httpx from fastapi.responses import StreamingResponse from fastapi import HTTPException try: # 验证URL if not url or not url.startswith(('http://', 'https://')): raise HTTPException(status_code=400, detail="Invalid image URL") # 使用异步客户端获取图片，添加常见浏览器头信息 headers = { 'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36...', 'Accept': 'image/webp,image/apng,image/svg+xml,image/*,*/*;q=0.8', } async with httpx.AsyncClient(timeout=30.0, follow_redirects=True, headers=headers) as client: response = await client.get(url) response.raise_for_status() # 获取内容类型 content_type = response.headers.get("content-type", "image/jpeg") # 验证是图片类型 if not content_type.startswith("image/"): raise HTTPException(status_code=400, detail="URL does not point to an image") # 返回图片流 return StreamingResponse( response.iter_bytes(), media_type=content_type, headers={ "Cache-Control": "public, max-age=86400", "Access-Control-Allow-Origin": "*", } ) except httpx.HTTPError as e: raise HTTPException(status_code=404, detail=f"Failed to fetch image: {str(e)}") except Exception as e: raise HTTPException(status_code=500, detail=f"Internal server error: {str(e)}")

解决方案详情

1. CORS跨域问题

问题：前端运行在 http://localhost:3001，尝试从 Netflix CDN (https://occ-0-2794-2219.1.nflxso.net) 加载图片时被浏览器阻止。

解决方案：通过后端代理图片请求，使浏览器认为是从同源获取图片。

实现：添加 /api/proxy/image 端点，前端通过此代理访问外部图片。

2. 500内部服务器错误

问题：追番链接API返回500错误，导致前端无法获取数据。

解决方案：改进错误处理和日志记录，确保API返回有意义的错误信息。

3. 图片抓取任务分配

推荐方案：后端负责图片处理，前端只负责显示。

  • 优势：安全性高，后端可控制可访问的图片源
  • 性能：后端可实现图片缓存和优化
  • 统一性：所有图片请求通过后端，便于监控和管理

4. 注意事项

  • 某些图片源（如Netflix）可能有严格的防爬虫机制，即使通过代理也可能无法访问
  • 建议后端定期检查图片URL的有效性
  • 可考虑实现图片缓存机制，减少对外部图片源的重复请求
