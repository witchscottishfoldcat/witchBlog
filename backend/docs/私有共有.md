使用步骤
设置MinIO存储桶策略：

bash
python scripts/setup_mixed_access.py
更新现有文件的URL：

bash
python scripts/update_to_mixed_urls.py
使用API切换文件公开状态：

bash
curl -X POST http://localhost:8000/api/v1/md-files/{file_id}/toggle-public
安全优势
明确的访问控制：公开文件和私有文件分开存储
灵活的策略：可以根据需要调整MinIO存储桶策略
自动URL管理：私有文件使用预签名URL，公开文件使用永久URL
API级别控制：确保只返回有权限访问的文件
