# WitchCat 项目详细介绍

## 项目概述

WitchCat是一个功能丰富的企业级Web应用框架，基于FastAPI构建，专注于个人博客、日记管理和内容展示。该项目不仅提供了完整的用户认证和权限管理系统，还包含了丰富的内容管理功能，如日记、技能展示、时间线、追番追剧列表等，是一个全面的个人网站解决方案。

## 核心技术栈

- **后端框架**: FastAPI 0.104.1
- **数据库**: MySQL/PostgreSQL + SQLAlchemy ORM
- **对象存储**: MinIO (用于图片和文件存储)
- **认证系统**: JWT令牌认证
- **数据库迁移**: Alembic
- **日志系统**: 结构化日志 + Loguru
- **API文档**: 自动生成的Swagger和ReDoc文档
- **容器化**: Docker + Docker Compose

### 6. 资源链接管理

- 其他个人网页链接

### 7. Markdown文件管理
- MD文件上传和展示

- 版本控制和历史记录

### 8. 项目展示
- 个人项目展示
- 项目描述和链接
- 项目分类和标签

### 9. 站点配置
- 站点基本信息设置
- 主题和样式配置

### 10. 图片代理服务

- 图片缓存和优化

## 系统架构

### 分层架构设计
项目采用清晰的分层架构，包括：
- **API层**: 处理HTTP请求和响应
- **服务层**: 实现业务逻辑
- **数据访问层**: 数据库操作
- **模型层**: 数据模型定义

### 数据库设计
- 使用SQLAlchemy ORM进行数据库操作
- 支持MySQL和PostgreSQL
- 使用Alembic进行数据库版本管理
- 包含完整的数据模型定义和关系映射

### 文件存储
- 使用MinIO作为对象存储服务
- 支持图片和文件的上传、存储和访问
- 实现永久URL和预签名URL两种访问方式
- 图片缩略图自动生成

### 安全特性
- JWT令牌认证
- CORS跨域保护
- 输入数据验证
- SQL注入防护
- 密码安全存储

## API接口设计

项目提供了完整的RESTful API，包括：
- 认证相关接口
- 用户管理接口
